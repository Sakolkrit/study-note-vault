# ViT 2020

> **In one line for a 12-year-old:** Cut the picture into little squares, treat each square like a word, and let a Transformer read them.

Paper: "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale", arXiv 2010.11929, read as version 2 of 3 June 2021 (ICLR 2021). Marks: "(paper, section)" was read in the paper; "(general knowledge)" is my own background; "(mine)" is my arithmetic.

## The problem
In language the [[Transformer]] had become the standard, but in vision convolutional networks still dominated. Does vision need convolutions at all? (paper, abstract and introduction). Earlier attempts either mixed attention with convolutions or replaced convolutions with special local attention patterns that "have not yet been scaled effectively on modern hardware accelerators" (paper, 1).

## What people did before
- Convolutional networks such as [[ResNet 2015]] were still the state of the art in large-scale image recognition, with attention sometimes added on top (paper, 1).
- Attention on pixels was too costly: "naive application of self-attention to images would require that each pixel attends to every other pixel", with quadratic cost, so earlier work used local neighbourhoods or sparse patterns (paper, 2).
- The closest earlier model, by Cordonnier and others (2020), used 2×2 patches and so only suited small images (paper, 2).

## The idea
Treat an image like a sentence. Cut it into fixed-size squares (patches), flatten each patch into a vector, and feed the sequence of vectors to a standard Transformer encoder, "with the fewest possible modifications" ([[Vision Transformer]]). The paper's finding: with enough pre-training data, "large scale training trumps inductive bias" (paper, 1).

## The architecture (figures)
The Vision Transformer (ViT) follows the original Transformer "as closely as possible" so that scalable language-model code can be used "almost out of the box" (paper, 3). It is a **Transformer encoder** (like [[BERT 2018]], no decoder) whose "words" are image patches (paper, Figure 1). Marks in each bullet say what the paper states and what is my background.

### Part by part
- **Cutting the image into patches.**
  - *What it does:* an image of size $H\times W\times C$ is cut into $N=HW/P^2$ patches of $P\times P$ pixels, each flattened into a vector of $P^2\cdot C$ numbers (paper, 3.1). For a 224×224 colour image with $P=16$: $N=196$ patches, each of $16\cdot16\cdot3=768$ numbers (mine).
  - *Why it matters:* $N$ is the length of the sequence the Transformer sees. Attention costs grow with the square of that length, so patches make it affordable: all 50,176 pixels as tokens would need $50{,}176^2\approx2.5$ billion attention scores per head per layer, against $197^2=38{,}809$ with patches (mine).
- **The linear projection $E$ (patch embedding).**
  - *What it does:* one trainable matrix maps each flattened patch to $D$ numbers, the Transformer's constant vector size (paper, 3.1).
  - *Why it matters:* it turns raw pixels into the "word vectors" the Transformer expects. It is the only layer that looks at pixel values directly, and (like a word embedding) it is learned. The paper shows that its learned filters resemble plausible basis functions for the fine structure within a patch (paper, 4.5, Figure 7 left).
- **The [class] token.**
  - *What it does:* a learnable extra vector placed in front of the patch embeddings, "similar to BERT's [class] token". Its output after the encoder is the image representation $y$ (paper, 3.1).
  - *Why it matters:* it gives the classification head one vector that has attended to all patches, without favouring any one patch (my reasoning). The paper says it keeps the design "as close as possible" to the original Transformer, and tested the alternative, averaging the patch outputs (global average pooling): a first attempt did very poorly, but the difference was fully explained by needing a different learning rate; with its own learning rate both worked similarly well (paper, Appendix D.3, Figure 9).
- **Position embeddings.**
  - *What it does:* a learned vector for each of the $N+1$ positions is added to the patch embeddings. They are plain 1D learnable embeddings (paper, 3.1).
  - *Why it matters:* attention alone ignores order, so without these the model could not tell where a patch came from: in the paper's ablation, ViT-B/16 with no position embedding scores 61.4% on 5-shot ImageNet against 64.2% with plain 1D embeddings (Table 8 below). The paper tried more advanced 2D-aware embeddings and saw no significant gain (Appendix D.4), and explains why: the learned 1D embeddings come to encode 2D structure by themselves: closer patches get more similar embeddings and patches in the same row or column look alike (paper, 4.5, Figure 7 centre).
- **The encoder block (repeated $L$ times).**
  - *What it does:* alternating multi-head self-attention (MSA) and MLP blocks. Layer normalization comes **before** each block and a residual connection **after** each. The MLP has two layers with a GELU nonlinearity (paper, 3.1). The paper writes the block as Eq. 2 and 3 (equations section below).
  - *Why it matters:* this is the standard Transformer ([[Attention Is All You Need 2017]]), and it makes self-attention **global** from the first layer: every patch can look at every other patch (paper, 3.1 and 4.5). Unlike the original Transformer's layer norm after each sub-layer, ViT puts it before (the placement is the paper's, citing Wang 2019 and Baevski 2019).
- **The classification head.**
  - *What it does:* an MLP with one hidden layer at pre-training time and a single linear layer at fine-tuning time, attached to the [class] output (paper, 3.1). At fine-tuning the pre-trained head is removed and a zero-initialised $D\times K$ layer is attached ($K$ = number of classes) (paper, 3.2).
  - *Why it matters:* only this small layer is new for a new task, so fine-tuning is cheap, as in BERT.
- **Model sizes and the patch-size name.**
  - *What it does:* three sizes (Table 1), "directly adopted from BERT" for Base and Large, plus a new Huge. The name ViT-L/16 means the Large model with 16×16 patches (paper, 4.1).
  - *Why it matters:* the sequence length is inversely proportional to the square of the patch size, so smaller patches mean longer sequences and a more expensive model (paper, 4.1). My arithmetic: ViT-B/32 has 49 patches, ViT-B/16 has 196, 4 times as many, so about 16 times as many attention scores.
- **The hybrid variant.**
  - *What it does:* feed the Transformer the feature map of a CNN instead of raw patches, with patches of size 1 by 1 (paper, 3.1).
  - *Why it matters:* it tests whether a bit of convolution helps. Result: hybrids beat pure ViT at small compute but the gap vanishes for larger models (paper, 4.4).
- **Inductive bias (what the design leaves out).**
  - *What it does:* a CNN has locality, 2D neighbourhood structure and translation equivariance built into every layer. In ViT only the MLP layers are local and translation-equivariant; self-attention is global. The 2D structure is used only when cutting patches and when adjusting position embeddings for a different image size (paper, 3.1).
  - *Why it matters:* this is why ViT needs a lot of data: spatial relations "have to be learned from scratch" (paper, 3.1). The evidence is in the data-requirement tables below.

## The core mechanism, step by step

### From an image to a prediction
**The idea (my analogy).** Read a picture the way you read a page: cut it into a grid of small tiles, give each tile a "word vector", number the tiles so their order is known, and let every tile look at every other tile to work out what the whole picture is.

1. **Cut into patches.**
   - *What it does:* a 224×224×3 image becomes 196 patches of 768 numbers each (with $P=16$) (paper, 3.1; numbers mine).
   - *Why it matters:* the image becomes a sequence, the one thing a Transformer can read.
2. **Project each patch to $D$ numbers.**
   - *What it does:* multiply every flattened patch by the matrix $E$ (768 by 768 for ViT-B/16, $589{,}824$ weights, mine). Result: 196 vectors of 768 numbers.
   - *Why it matters:* it gives every patch a learned "word vector".
3. **Add the [class] token.**
   - *What it does:* a learnable vector is placed first, making 197 vectors.
   - *Why it matters:* it is the slot whose final state becomes the answer.
4. **Add position embeddings.**
   - *What it does:* add a learned vector for each of the 197 positions ($197\times768=151{,}296$ numbers, mine).
   - *Why it matters:* patch order and location enter the model here and nowhere else.
5. **Run $L$ encoder blocks.**
   - *What it does:* in each block, normalise, apply multi-head self-attention, add the input back; normalise, apply the MLP, add back (Eq. 2 and 3). Every vector keeps its size, 197 by $D$.
   - *Why it matters:* attention lets every patch gather information from every other patch, from the very first layer; the MLP processes each vector on its own.
6. **Read out the [class] vector.**
   - *What it does:* normalise the final [class] vector to get $y$ (Eq. 4) and apply the head: a hidden layer at pre-training, one linear layer at fine-tuning.
   - *Why it matters:* the [class] vector has attended to everything, so it summarises the image; the head turns it into one score per class.

**Worked example (mine; tiny numbers).** A 4×4 one-channel image with $P=2$ gives $N=4$ patches of 4 numbers; take $D=2$. One patch $x_p=(1,0,0,1)$ and $E=\begin{pmatrix}1&0\\0&1\\1&0\\0&1\end{pmatrix}$.
- Step 2: $x_pE=(1,1)$.
- Step 3 and 4: with a class token $(0.5,0.5)$, position embedding $(0.1,0)$ for position 0 and $(0,0.1)$ for position 1: the [class] input is $(0.6,\,0.5)$ and the patch input is $(1,\,1)+(0,0.1)=(1,\,1.1)$.
- Meaning: each patch becomes a short vector that also carries its position.

**Shapes for ViT-B/16 on a 224×224 image (mine).**

| Stage | Shape (rows by columns) |
|---|---|
| Image | $224\times224\times3$ |
| Flattened patches | $196\times768$ |
| After $E$ | $196\times768$ |
| With [class] token | $197\times768$ |
| After position embeddings, and after every encoder block | $197\times768$ |
| Attention scores per head | $197\times197=38{,}809$ |
| Output used for classification | the first row, $768$ numbers |

### Fine-tuning at a higher resolution
1. **Pre-train at one resolution (224) and fine-tune at a larger one (for example 384 or 512).** The paper notes it is "often beneficial to fine-tune at higher resolution than pre-training" (paper, 3.2).
2. **Keep the patch size the same.** The sequence gets longer: at 384 with $P=16$ there are $24\times24=576$ patches, at 512 there are $1{,}024$ (mine).
3. **Interpolate the position embeddings in 2D.** The pre-trained position embeddings no longer fit the longer sequence, so they are resized according to their location in the original image (paper, 3.2).
4. **Why it matters:** this resolution change and the patch cutting are "the only points at which an inductive bias about the 2D structure of the images is manually injected" (paper, 3.2).

## The equations
**1. The patch embedding** (Eq. 1)

$$
z_0=\left[x_{\text{class}};\ x_p^{1}E;\ x_p^{2}E;\ \cdots;\ x_p^{N}E\right]+E_{\text{pos}},\qquad E\in\mathbb{R}^{(P^2\cdot C)\times D},\ E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}
$$

**Where:**
- $x_p^{i}$: the $i$-th flattened patch ($P^2\cdot C$ numbers); $N=HW/P^2$ patches.
- $E$: the learned projection to $D$ numbers. $x_{\text{class}}$: the learnable [class] vector. The semicolons stack them into one sequence of $N+1$ rows.
- $E_{\text{pos}}$: the learned position embeddings, one row per position.

**Matters:** this one line turns the image into the sequence the encoder reads. Without $E_{\text{pos}}$ the model has no idea which patch is where; without $x_{\text{class}}$ there is no single slot for the answer.

**Example (tiny numbers):** as in the worked example: $x_p=(1,0,0,1)$ with the given $E$ gives $(1,1)$; class vector $(0.5,0.5)$; position embeddings $(0.1,0)$ and $(0,0.1)$.
- Row 0 (class): $(0.5,0.5)+(0.1,0)=(0.6,\,0.5)$. Row 1 (patch): $(1,1)+(0,0.1)=(1,\,1.1)$.
- Meaning: the sequence now has a class slot first, then one vector per patch, each carrying its position.

**2. The attention half of an encoder block** (Eq. 2)

$$
z'_{\ell}=\mathrm{MSA}\!\left(\mathrm{LN}(z_{\ell-1})\right)+z_{\ell-1},\qquad \ell=1\ldots L
$$

**Where:**
- $z_{\ell-1}$: the sequence entering block $\ell$. $\mathrm{LN}$: layer normalization (rescale each vector to mean 0 and spread 1, then a learned scale and shift). $\mathrm{MSA}$: multi-head self-attention.
- The "$+z_{\ell-1}$" is the residual connection: the input is added back to the attention's output.

**Matters:** the normalisation keeps numbers in a steady range before attention, and the residual lets the block add a correction instead of rewriting its input (the same idea as [[ResNet 2015]]). Putting LN **before** the block, not after, is the paper's choice (citing earlier work).

**Example (tiny numbers):** $z_{\ell-1}=(1,\,1.1)$ and suppose the attention output is $(0.2,\,-0.1)$.
- Result: $z'_{\ell}=(1.2,\,1.0)$.
- Layer norm itself, for a vector $(1,3)$: mean 2, spread 1, so $\mathrm{LN}(1,3)=(-1,\,1)$ (ignoring the tiny constant added for stability and the learned scale).
- Meaning: the attention output is a small correction added onto the input.

**3. The MLP half of an encoder block** (Eq. 3)

$$
z_{\ell}=\mathrm{MLP}\!\left(\mathrm{LN}(z'_{\ell})\right)+z'_{\ell},\qquad \ell=1\ldots L
$$

**Where:**
- $z'_{\ell}$: the output of the attention half. $\mathrm{MLP}$: two linear layers with a GELU between them, applied to each vector separately. The "$+z'_{\ell}$" is again the residual.

**Matters:** attention mixes information between patches; the MLP then processes each patch's vector by itself. Together they are one block.

**Example (tiny numbers):** $z'_{\ell}=(1.2,\,1.0)$ and suppose the MLP output is $(-0.3,\,0.1)$.
- Result: $z_{\ell}=(0.9,\,1.1)$.
- Meaning: another small correction; the vector keeps its size and is passed to the next block.

**4. The image representation** (Eq. 4)

$$
y=\mathrm{LN}\!\left(z_{L}^{0}\right)
$$

**Where:**
- $z_L^{0}$: the output of the last block ($L$) at position 0, the [class] token. $\mathrm{LN}$: layer normalization. $y$: the image representation that goes to the classification head.

**Matters:** this is the one vector that stands for the whole image; the head turns it into class scores.

**Example (tiny numbers):** $z_L^{0}=(2,4)$: mean 3, spread 1, so $y=(-1,\,1)$ (my arithmetic, ignoring the stability constant).

**5. Self-attention inside MSA** (Eq. 5 to 7, Appendix A)

$$
[q,k,v]=zU_{qkv},\qquad A=\operatorname{softmax}\!\left(qk^{\top}/\sqrt{D_h}\right),\qquad \mathrm{SA}(z)=Av
$$

**Where:**
- $z\in\mathbb{R}^{N\times D}$: the sequence; $U_{qkv}\in\mathbb{R}^{D\times3D_h}$: one learned matrix that produces the queries, keys and values; $D_h$ is the size per head.
- $A\in\mathbb{R}^{N\times N}$: attention weights from the pairwise similarity of queries and keys. Multi-head attention runs $k$ of these in parallel and joins the results (paper, Appendix A; the same as in [[Attention Is All You Need 2017]]).

**Matters:** $A$ says how much each patch looks at every other patch; the $\sqrt{D_h}$ stops the scores growing with the head size (see the Attention note for why).

**Example (tiny numbers):** two patches with $q=k=v=\begin{pmatrix}1&0\\0&1\end{pmatrix}$ and $D_h=2$.
- Scores $qk^{\top}/\sqrt2$: $\begin{pmatrix}0.707&0\\0&0.707\end{pmatrix}$; softmax per row: $A=\begin{pmatrix}0.670&0.330\\0.330&0.670\end{pmatrix}$.
- $\mathrm{SA}(z)=Av=A$, so each patch's output is 67% itself and 33% the other patch.
- Meaning: each patch is mostly itself, with a share of its neighbour.

## What they found
ViT matches or beats the best convolutional networks on many image benchmarks when pre-trained on large data, at a lower pre-training cost. The best model reaches 88.55% on ImageNet, 90.72% on ImageNet-ReaL, 94.55% on CIFAR-100 and 77.63% on the 19-task VTAB suite (paper, 1 and Table 2). The abstract's claim: excellent results compared with state-of-the-art convolutional networks "while requiring substantially fewer computational resources to train". On a smaller pre-training set such as ImageNet alone, ViT is "a few percentage points below ResNets of comparable size" (paper, 1).

## Questions I had, answered

**Why patches and not pixels?** Attention compares every token with every other, so cost grows with the square of the number of tokens. Treating the 50,176 pixels of a 224×224 image as tokens would need about 2.5 billion scores per head per layer; 197 patch tokens need 38,809 (mine). That is the reason the paper cites for earlier work using local or sparse attention (paper, 2).

**Why does ViT need so much data when a CNN does not?** A CNN has locality and translation equivariance built into every layer. ViT does not, so it must learn spatial relations from scratch (paper, 3.1). The paper's evidence: on ImageNet alone ViT-L/16 is worse than ViT-B/16 and than comparable ResNets; with 300 million images ViT overtakes (Table 5 and Figure 4). Its summary: "the convolutional inductive bias is useful for smaller datasets, but for larger ones, learning the relevant patterns directly from data is sufficient, even beneficial" (paper, 4.3).

**Does ViT know where a patch is?** Only through the learned position embeddings. They start with no 2D information, but after training closer patches have more similar embeddings and rows and columns show up, which the paper says explains why hand-built 2D embeddings did not help (paper, 3.1 and 4.5).

**Does self-attention really use the whole image?** Yes, from the first layers: some heads attend over most of the image already in the lowest layers, while other heads stay local; the average "attention distance" grows with depth. Hybrids with a ResNet in front show less of the local heads, suggesting those local heads do the job of early convolutions (paper, 4.5).

**Why a [class] token and not an average of the patch outputs?** The paper says the token is inherited from the text Transformer, to stay close to it. It also tested averaging the patch outputs (global average pooling) with a linear classifier: a first attempt performed very poorly, but the paper found the gap was fully explained by needing a different learning rate; with the right one the two worked similarly well (Appendix D.3, Figure 9). So the token is a convenience of design, not a necessity.

**Can ViT learn without labels?** A small test: masked patch prediction, like BERT's masked words. ViT-B/16 reached 79.9% on ImageNet, 2% better than training from scratch but 4% behind supervised pre-training. The authors call it preliminary (paper, 4.6).

## Why it mattered
Showed one architecture could serve text and images.

## Limits and open questions
- Needs a lot of pre-training data to shine (the abstract's condition "when pre-trained on large amounts of data"); on ImageNet-sized data it is a few points below comparable ResNets (paper, 1 and 4.3).
- Only classification is tested; the authors list detection and segmentation as the next challenges (paper, 5).
- Self-supervised pre-training still trails supervised pre-training by about 4% (paper, 4.6).
- Further scaling "would likely lead to improved performance": the models did not saturate in the range tried (paper, 4.4 and 5).
- The cost comparison depends on training choices (schedule, optimizer, weight decay), as the paper itself warns (4.2).
- The best results use JFT-300M, an in-house data set (paper, 4.1), which others could not use.

#flashcards/research/concept #flashcards/topic/research-vision What are the parts of the Vision Transformer, and what does each do?::Patches: the image cut into $N=HW/P^2$ flattened pieces of $P^2C$ numbers. #flashcards/research/concept #flashcards/topic/research-vision What inductive bias does ViT leave out compared with a CNN?::A CNN has locality, 2D neighbourhood structure and translation equivariance in every layer. So spatial relations are learned from scratch, which is why ViT needs lots of data.

#flashcards/research/concept #flashcards/topic/research-vision What are the steps from an image to a ViT prediction?
?
1. Cut into patches (196 of 768 numbers for 224×224 with 16×16). 2. Project each with $E$ to $D$ numbers. 3. Prepend the [class] token (197 vectors). 4. Add position embeddings. 5. Run $L$ encoder blocks (norm, attention, add; norm, MLP, add). 6. Take the [class] vector, normalise it, and apply the head.

#flashcards/research/concept #flashcards/topic/research-vision How is ViT fine-tuned at a higher resolution?::Keep the patch size, which makes the sequence longer (384 gives 576 patches, 512 gives 1,024), and resize the pre-trained position embeddings by 2D interpolation according to their location in the original image. Fine-tuning at higher resolution is often beneficial.

#flashcards/research/concept #flashcards/topic/research-vision Write the ViT patch embedding and explain each symbol.
?
$$z_0=\left[x_{\text{class}};\ x_p^{1}E;\ \cdots;\ x_p^{N}E\right]+E_{\text{pos}},\quad E\in\mathbb{R}^{(P^2C)\times D},\ E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}$$
- $x_p^i$: the $i$-th flattened patch; $E$: the learned projection to $D$ numbers; $x_{\text{class}}$: the learnable [class] vector; $E_{\text{pos}}$: learned position embeddings, one row per position.
- Turns the image into the sequence the encoder reads; without $E_{\text{pos}}$ patch locations are unknown.

#flashcards/research/concept #flashcards/topic/research-vision Patch embedding example: $x_p=(1,0,0,1)$, $E$ rows $(1,0),(0,1),(1,0),(0,1)$, class $(0.5,0.5)$, position embeddings $(0.1,0)$ and $(0,0.1)$. What are the first two rows of $z_0$?
?
$x_pE=(1,1)$. Row 0 (class): $(0.5,0.5)+(0.1,0)=(0.6,0.5)$. Row 1: $(1,1)+(0,0.1)=(1,1.1)$ (my arithmetic).

#flashcards/research/concept #flashcards/topic/research-vision Write the attention half of a ViT encoder block and explain each symbol.
?
$$z'_\ell=\mathrm{MSA}(\mathrm{LN}(z_{\ell-1}))+z_{\ell-1}$$
- $z_{\ell-1}$: the sequence entering block $\ell$; LN: layer norm (rescales each vector to mean 0 and spread 1, then a learned scale and shift), applied before the block; MSA: multi-head self-attention.
- The "+" is the residual connection: the input is added back, so the block adds a correction instead of rewriting it. Putting LN before the block is the paper's choice.

#flashcards/research/concept #flashcards/topic/research-vision Attention half example: $z_{\ell-1}=(1,1.1)$ and the attention output is $(0.2,-0.1)$. What is $z'_\ell$?
?
$z'_\ell=(1.2,\,1.0)$ (my arithmetic). Layer norm of $(1,3)$ is about $(-1,1)$ (mean 2, spread 1).

#flashcards/research/concept #flashcards/topic/research-vision Write the MLP half of a ViT encoder block and explain each symbol.
?
$$z_\ell=\mathrm{MLP}(\mathrm{LN}(z'_\ell))+z'_\ell$$
- $z'_\ell$: the output of the attention half; MLP: two linear layers with a GELU between, applied to each vector separately; LN before; "+" is the residual.
- Attention mixes information between patches; the MLP then processes each patch's vector by itself.

#flashcards/research/concept #flashcards/topic/research-vision MLP half example: $z'_\ell=(1.2,1.0)$ and the MLP output is $(-0.3,0.1)$. What is $z_\ell$?
?
$z_\ell=(0.9,\,1.1)$ (my arithmetic): another small correction; the vector keeps its size and goes to the next block.

#flashcards/research/concept #flashcards/topic/research-vision Write ViT's image representation and explain each symbol.
?
$$y=\mathrm{LN}\!\left(z_L^{0}\right)$$
- $z_L^{0}$: the last block's output at position 0, the [class] token, which has attended to all patches; LN: layer norm; $y$ goes to the classification head. Example: $z_L^0=(2,4)$ gives $y\approx(-1,1)$.

#flashcards/research/concept #flashcards/topic/research-vision Write the self-attention equations in the ViT appendix and explain each symbol.
?
$$[q,k,v]=zU_{qkv},\qquad A=\operatorname{softmax}\!\left(qk^{\top}/\sqrt{D_h}\right),\qquad \mathrm{SA}(z)=Av$$
- $z$: the sequence ($N\times D$); $U_{qkv}$: one matrix giving queries, keys and values; $D_h$: size per head; $A$ ($N\times N$): attention weights from query-key similarity. Multi-head attention runs $k$ of these in parallel (same as the original Transformer).

#flashcards/research/concept #flashcards/topic/research-vision Self-attention example: $q=k=v$ the identity matrix, $D_h=2$. What are $A$ and the output?
?
Scores divided by $\sqrt2$: $0.707$ on the diagonal and 0 elsewhere. $A=\begin{pmatrix}0.670&0.330\\0.330&0.670\end{pmatrix}$ and $\mathrm{SA}(z)=Av=A$: each patch is 67% itself and 33% the other (my arithmetic).
