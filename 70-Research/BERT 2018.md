# BERT 2018

> **In one line for a 12-year-old:** Hide some words in a sentence and make the network guess them from both sides. After that it understands language well enough to be tuned for many jobs.

## The problem
Use unlabelled text to build one model that many language tasks can start from.

## What people did before
One-direction language models and task-specific architectures, plus word vectors like [[Word2Vec 2013]].

## The idea
Pre-train a deep bidirectional [[Transformer]] by jointly conditioning on left and right context, then fine-tune with one extra output layer ([[BERT]]).

## What they found
New best results on eleven tasks, including GLUE 80.5% (7.7 points absolute gain), MultiNLI 86.7% (+4.6), SQuAD v1.1 F1 93.2 (+1.5) and SQuAD v2.0 F1 83.1 (+5.1) (abstract).

## Why it mattered
Made 'pre-train, then fine-tune' the default for language understanding.

## Limits and open questions
An encoder that reads text, not a text generator, so it is not used for chat ([[LLM]]).

## Concepts used
[[Pre-training]], [[Fine-tuning]], [[Self-Supervised Learning]], [[Tokenization]]

## Reading trail
- **Came from:** [[Attention Is All You Need 2017]] and [[ELMo 2018]]
- **Led to:** [[GPT-3 2020]]
