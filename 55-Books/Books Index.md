# Book notes

One folder per book: an index note named after the book, and one note per chapter. A chapter note summarises in my own words and links to the concept notes where the detail lives. Each note says what was read and what was not.

## How to add a book
1. Make a folder `55-Books/<Book name>/` with an index note from `90-Templates/Book.md` and one note per chapter from `90-Templates/Chapter.md`.
2. Add the book to the list above.
3. Add its flashcard topic `book-<short-name>` to the topic list in `CLAUDE.md`.
